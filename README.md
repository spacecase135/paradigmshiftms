# Paradigm Shift MS

Public website source for `https://paradigmshiftms.com/`.

This repository contains only public-safe website material. The private PSMS development source of truth is maintained separately.

## Privacy posture

The site uses local HTML and CSS only. It has no analytics, cookies, telemetry, external fonts, third-party scripts, CDN resources, embeds, or forms. Its inquiry route is a visible `mailto:` link; the visitor's and recipient's email providers handle any message sent.

## Release boundary

This repository contains public-safe material only. Private research, funding strategy, sensitive records, and technical/IP material must remain in their separate private records.

## Local preview

Open `index.html` directly or serve this folder with a simple local static server. Review all changes before publishing.
