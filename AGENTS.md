# ParadigmShiftMS.com public repository policy

This is a public website repository. Never place private PSMS development records, health data, credentials, unpublished methods, contractor information, or IP-review material here.

Do not add analytics, cookies, pixels, telemetry, session replay, ads, external fonts, third-party embeds, external JavaScript, CDN resources, or hidden/networked behavior without Casey's prior informed approval. Explain data collected, recipients, purpose, necessity, retention if known, consequences of omission, and alternatives before requesting approval.

Use only material explicitly cleared by the private repository's public-release process. Preserve evidence labels and avoid medical, partnership, funding, regulatory, or performance claims that are not supported and current.

Keep commits small and reviewable. Human review is required before deployment. If Casey says `ALASKA`, provide detailed click-by-click instructions for the current step.
